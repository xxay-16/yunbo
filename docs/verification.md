## v0.3.0：速度显示与断点续传

- `go test -race ./...` 通过，覆盖速度窗口、暂停后归零、恢复基线、上传和下载重启恢复。
- 分片任务恢复时跳过服务端已确认的分片，包括服务端接收成功但客户端未收到应答的分片。
- 同大小、同修改时间但内容已变化的源文件被完整 SHA-256 校验拒绝；Windows 上传句柄禁止写入。
- 过期上传会话明确报错，不会自动从零重建；禁止使用另一个账号继续任务；损坏的任务记录不会被覆盖。
- 下载续传发送实际文件偏移的 Range，拒绝忽略 Range、错误分段、变化的 ETag 或元数据，拒绝前不修改原有部分文件。
- 任务记录不保存账号令牌和目录密码，恢复受保护下载时要求重新输入密码。

界面联调使用实际 Wails Go 后端、隔离的 APPDATA 与本地模拟服务：12 MiB 上传及 4 MiB 下载均显示非零实时速度和预计剩余时间。分别暂停后关闭开发程序，再次启动并重新登录，两个任务均从断点继续并完成。上传由模拟服务核对 SHA-256，下载与原始测试内容逐字节比对一致。下载 SHA-256 为 `5947c00ce4da5eac3e8b3731df34e42a2d7b7e88bdb7bd93b8152afcedaa2f92`。

已确认目标云端公开配置为 OpenList v4.2.9、`multipart_enabled=true`，并核对该版本官方协议。此次传输联调使用合成测试文件，未对用户真实云盘进行长时间大文件传输。服务端重启或离线超过会话有效期后的恢复能力受 OpenList 实现限制。
